# 안전한 리팩터링

동작 보존 경계를 정하고, 구조 편집 전에 검증을 확보한다.

- 기능 변경은 리팩터링 밖에 둔다. 섞이면 커밋을 나눈다.
- 소유권 경계는 한 번에 하나만 옮긴다.
- 명시적으로 범위에 넣지 않은 한 공개 인터페이스·실패 동작·순서·호환성을 보존한다.
- 중간 상태도 빌드·테스트 가능하게 유지한다. 커밋 단위마다 `scripts/verify.py`가 통과해야 한다.
- 정확성에 필요하지 않은 의존성·설정 증가를 피한다.

변경 후 같은 증명을 다시 돌린다. 동작이 일치하고 요청한 구조가 되면 멈춘다.
