# 검증하고 멈추기

인수 조건을 가장 작은 충분한 증명 집합으로 바꾼다.

- 저장소 상태가 같다면 아직 유효한 기존 결과를 재사용한다.
- 넓은 게이트보다 대상이 좁은 검사를 먼저 돌린다.
- 통과·실패·실행 불가·차단을 정확히 구분한다. skip이나 not_run을 통과로 적지 않는다.
- 검증 요청에 수정이 포함되지 않았다면 제품 코드를 고치지 않는다.
- 기준을 만족한 뒤 다듬기·정리·무관한 테스트 추가를 하지 않는다.

이 프로젝트의 기본 게이트는 `./.venv/Scripts/python.exe scripts/verify.py`다. `--fast`는 ruff·기동·설정 drift만, `--frontend`는 프론트 lint/test/build를 강제한다. 결과는 `.harness/runs/<id>/result.json`에 남는다.

인수 증명이 끝나면 즉시 멈춘다. 실행한 명령, 결과, 남은 위험만 보고한다.
